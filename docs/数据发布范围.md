# 项目资料范围

本仓库包含原项目的全部代码、数据、资料和成果文件。原项目代码原件保存在 原始代码/，适合直接运行的整理版保存在 代码/。

| 内容 | 位置 |
| --- | --- |
| 企业报告 PDF | 原始数据/公司年报PDF/ |
| 财务与 TFP 原始压缩包及来源说明 | 原始数据/ |
| 财务、城市宏观、企业映射、政策名单和分析面板 | 输入数据/ |
| 回归表、企业诊断、策略回测、Excel、日志及图表 | 运行结果/ |
| 原研究报告 | 仓库根目录的 DOC 文件 |
| 原始组员说明 | 仓库根目录的 组员说明.txt |
| 逐文件完整性清单 | 项目文件校验.csv |

原项目 876 个文件均保留；清单记录源文件路径、仓库路径、字节数和 SHA-256。原项目的 代码/ 对应仓库中的 原始代码/，其余原文件保持同名目录。

整理版额外提供 annual_report_alias_map.csv、stock_city_map.csv、ppi_deflator.csv 和 tfp_deflator.csv，供相对路径版本直接读取。它们来自原项目的既有映射或原始脚本配置。

PDF、Excel、压缩包、DOC 报告和 PNG 图片由 Git LFS 管理。文件内容存放在 GitHub 的大文件存储中，Git 仓库记录对应指针。安装 Git LFS 后克隆并执行 git lfs pull 可取回文件内容。

环境密钥、Python 缓存、虚拟环境和本轮新增运行目录 local_outputs/ 不加入版本控制。提交检查保留文件格式、凭据检测、LFS 指针与原项目校验清单核对功能。
