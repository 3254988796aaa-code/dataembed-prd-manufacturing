# 数据发布范围

本项目的公开范围以“数据资料仅允许企业年报”为边界。当前版本只发布程序、说明和年报文件索引，不包含 PDF 正文或其他数据文件。

| 内容 | 当前公开版处理 |
| --- | --- |
| Python 程序 | 保留方法实现，移除内嵌的价格指数、企业映射和回归结果常量 |
| 企业年报 | 发布原始文件名、年份、报告类型和文件大小索引；PDF 留在本地 |
| 财务数据库、TFP 数据包 | 不发布 |
| 城市宏观经济、财务及其他表格 | 不发布 |
| 处理后面板、企业别名和政策名单 | 不发布 |
| 回归表、模拟结果、运行日志及图表 | 不发布 |
| 含经济数据或研究结果的完整报告 | 不发布 |
| 组员说明及个人信息 | 不发布 |

代码中的价格指数改为读取本地 CSV。仪表盘的模拟系数由使用者提供的本地样本估计，不保存原研究的数值。

原来的“图片生成.py”内含写死的研究结果，因此不纳入公开版。主分析脚本仍保留根据本地输入动态生成图表的功能。

## 本地隔离

- private_data/：本地经济数据和配置；不加入版本控制。
- local_outputs/：所有运行结果；不加入版本控制。
- 年报 PDF：即使放入 data/annual_reports/，当前规则也默认忽略，避免批量提交大文件。
- .gitignore 使用允许清单；提交检查再次核对实际暂存的文件路径和已知内嵌数据位置。

提交检查是辅助措施。新增程序或调整公开范围时，应人工检查代码、文字、截图和历史提交中的数据内容。
