# 方法与当前限制

- 年报文本基于可提取的 PDF 文本；扫描件需要额外 OCR，当前脚本没有实现 OCR。
- 关键词与实施证据描述的是文本披露，不等同于企业真实的数据资产规模或数字化投入。词典、证据规则和样本范围需要结合研究目的核验。
- 原始文件目录可能含半年度报告等条目。公开索引保留原始名称并标明类型，使用时应核对期间、报告类型、重复文件及企业名称匹配。
- 面板回归采用双向去均值和企业聚类标准误。对非平衡面板，单次双重去均值不必然等价于严格吸收两个固定效应，正式估计前应核对样本结构和实现。
- TFP计算.py 保留原研究中的简化估计实现。其 GMM 分支使用水平 OLS 残差，不能视为完整的 GMM；OP/LP 标签也应结合源代码核对估计步骤。
- 策略模拟属于基于估计关系的情景计算，不能直接解释为已识别的因果效应或未来真实收益。仪表盘系数由本地数据重新估计。
- Numba 版本保留原有数值逻辑加速实现，速度随环境和文件规模变化，没有在公开版中发布性能基准结论。
- 仓库提供完整原始资料与既有结果。重建时仍应核对脚本版本、样本筛选、缺失值处理和估计口径；不同环节的中间文件不会自动相互覆盖。

整理版保留研究方法，调整了相对路径、输入配置和新增结果目录；原始代码与原始结果另行完整保留。未对原研究模型做完整方法审计。
