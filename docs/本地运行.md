# 本地运行

Python 3.10+。在仓库根目录运行命令。公开版没有附带经济数据，以下各流程需要相应的本地输入。

## 1. 安装与数据路径

```bash
python -m pip install -r requirements.txt
```

默认从 private_data/ 读取输入，将结果写入 local_outputs/。两个目录均被版本控制忽略。

已有本地数据时，可在 PowerShell 中配置：

```powershell
$env:DATAEMBED_INPUT_DIR = '本地输入文件夹的绝对路径'
$env:DATAEMBED_OUTPUT_DIR = '本地输出文件夹的绝对路径'
$env:DATAEMBED_ANNUAL_REPORT_DIR = '本地年报PDF文件夹的绝对路径'
```

不要将这些本地数据或运行结果提交到仓库。

## 2. 年报文本分析

准备公司年报 PDF 和本地 alias_map.csv。文本处理使用的映射字段为 stock_code、firm_name、aliases，证券代码应保存为文本以保留前导零。

```bash
python 代码/年报处理.py --pdf_dir "本地年报文件夹" --alias_file "本地alias_map.csv" --output_dir "本地结果文件夹"
python "代码/年报文本处理（Numba JIT 加速版）.py" --help
```

--max_pages 可以限制单份 PDF 的处理页数，用于检查流程；正式研究应核对全文覆盖情况。股票代码及别名可由已获使用权限的本地资料准备，make_alias.py 也提供 Excel 映射生成逻辑。

## 3. 面板与 TFP

整合脚本使用：TFP_2017-2024.xlsx、上市公司财务数据_最终表02.xlsx、计算TFP所需的原始财务数据面板.xlsx、datembed_panel.csv，以及可选的城市宏观数据.xlsx。

原内嵌配置改为三个本地 CSV 文件：

| 文件 | 字段 |
| --- | --- |
| stock_city_map.csv | firm_name、code、city |
| ppi_deflator.csv | year、deflator |
| tfp_deflator.csv | year、deflator |

两个平减序列用于不同处理环节，应由使用者自行准备并核对经济含义与基期。代码不提供数值示例或默认实测序列。

```bash
python 代码/TFP计算.py
python 代码/整合生成最终面板数据.py
python "代码/整合面板数据（Polars 全兼容版）.py"
```

每个脚本的结果写入本地输出目录；后续流程读取输入目录。阶段切换时，请将需要的中间文件放入本地输入目录，或使用适当的本地目录配置。

## 4. 主分析、回测及仪表盘

主分析使用 panel.csv 和企业映射 alias_map.csv。注意：主分析沿用原研究的映射表结构，需要股票代码、上市公司简称、上市公司全称、主要子公司 / 品牌 / 曾用名；它与文本处理的三列映射表不是同一种结构，应按流程分别准备。

可选政策名单使用 industrial_internet_demo.csv、gd_smart_mfg_demo.csv、national_smart_mfg_demo.csv、little_giant_demo.csv。它们均只在本地读取。

panel.csv 需要证券代码、年份、DataEmbed 指标、绩效及控制变量等字段。具体字段定义可查看 run_all.py 中 DEFAULT_CONTROLS、run_regressions 及 classify_stage。不要将带真实数据的示例面板提交到仓库。

```bash
python 代码/run_all.py --input_dir "本地输入目录" --output_dir "本地输出目录"
python 代码/strategy_backtest.py
python -m streamlit run 代码/app.py
```

无经济数据时，可以查看代码、命令行帮助和仪表盘的数据准备提示；完整回归和企业诊断需要自行提供本地输入。
