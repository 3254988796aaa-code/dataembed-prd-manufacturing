# 完整项目运行

Python 3.10+。先安装 Git LFS 并取回大文件，再在仓库根目录执行：

```bash
git lfs install
git lfs pull
python -m pip install -r requirements.txt
```

## 1. 默认路径

整理版 代码/ 默认读取 输入数据/，年报位于 原始数据/公司年报PDF/。新增结果写入 local_outputs/，保留原有 运行结果/ 便于对照。

需要换用其他文件夹时，可在 PowerShell 中配置：

```powershell
$env:DATAEMBED_INPUT_DIR = '输入文件夹的绝对路径'
$env:DATAEMBED_OUTPUT_DIR = '输出文件夹的绝对路径'
$env:DATAEMBED_ANNUAL_REPORT_DIR = '年报PDF文件夹的绝对路径'
```

## 2. 直接运行现有面板分析

```bash
python 代码/run_all.py
python 代码/strategy_backtest.py
python -m streamlit run 代码/app.py
```

主分析使用已附带的 panel.csv、alias_map.csv 和政策名单，生成回归、阶段诊断、稳健性检验、工作簿与图表。仪表盘的策略模拟系数由当前输入样本重新估计。

## 3. 年报文本分析

```bash
python 代码/年报处理.py --help
python "代码/年报文本处理（Numba JIT 加速版）.py" --help
python 代码/年报处理.py
```

默认使用 输入数据/annual_report_alias_map.csv，字段为 stock_code、firm_name、aliases，来自原项目的年报处理映射。它与主分析使用的 alias_map.csv 不同；后者保留股票代码、上市公司简称、上市公司全称、主要子公司 / 品牌 / 曾用名四列。

--pdf_dir、--alias_file、--output_dir 可以覆盖路径，--max_pages 可以限制每份 PDF 的处理页数用于快速检查。完整年报处理应核对页数与报告期间。

## 4. 从财务与文本结果重建面板

已提供 TFP_2017-2024.xlsx、上市公司财务数据_最终表02.xlsx、计算TFP所需的原始财务数据面板.xlsx、datembed_panel.csv 和城市宏观数据.xlsx。

整理版从 输入数据/ 读取原脚本的配置：

| 文件 | 字段 |
| --- | --- |
| stock_city_map.csv | firm_name、code、city |
| ppi_deflator.csv | year、deflator |
| tfp_deflator.csv | year、deflator |

```bash
python 代码/TFP计算.py
python 代码/整合生成最终面板数据.py
python "代码/整合面板数据（Polars 全兼容版）.py"
```

每个脚本的新增结果写入 local_outputs/，后续流程默认仍读取 输入数据/ 的既有文件。若要串联一轮全新重建，请将需要的中间产物放入相应输入目录，或调整目录参数。

## 5. 原始版本与图表

原始代码/ 保留原项目所有脚本及其配置。部分原始脚本包含旧电脑绝对路径，直接运行前需调整。代码/ 是相对路径整理版。

代码/图片生成.py 保留原论文内嵌结果的绘图逻辑，并将图片写入本地输出目录；运行时可能弹出 Matplotlib 窗口。原有图表已经保存在 运行结果/ 中。

使用 项目文件校验.csv 可核对全部原项目文件。代码/ 下的整理版不属于原件校验范围，原始代码/ 中的脚本属于原件校验范围。
