# 企业年报资料

annual_report_index.csv 为本项目本地年报资料的文件目录，仅包含文件名、文件大小、文件名中的年份与报告类型，不含年报全文、财务指标或数据库内容。

本地原始目录有 776 份 PDF，总计约 3.5 GiB。为控制仓库体积，本次不上传 PDF，原件保留在项目本地目录。使用者可自行从上市公司公告渠道准备年报，然后通过 DATAEMBED_ANNUAL_REPORT_DIR 或 --pdf_dir 指向本地目录。

索引中的“报告类型”按文件名识别，不能替代对正文期间的核验。历史文件中包含半年度报告条目，研究前应按自己的样本口径筛选。

本仓库当前的数据发布边界仅允许企业年报资料；经济数据库、处理后面板、回归输出和完整研究报告不在公开范围内。年报 PDF 当前同样默认被忽略，新增上传应单独检查文件来源、内容和体积。
